# heart_popup

a node that can be attached and used to display how much health something has, can work with other stats too

## Installation

Make sure to download the ChillCube Developer tools: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Using the Godot Plugin
Enable the **ChillCube Tools** plugin, then paste the repo URL into the Clone tab.

### Linux / CLI
```bash
clone-gd-addon https://github.com/ChillCube/heart_popup.git
```

## Documentation
https://github.com/ChillCube/heart_popup/blob/main/DOCUMENTATION.md

## Deinstallation
Use the CC Tools panel in Godot, or run:
```bash
remove-gd-addon heart_popup
```

## For Developers
```bash
push-all-addons
```
